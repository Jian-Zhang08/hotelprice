# Contributing to Yellowstone Hotel Price Monitor

First off, thank you for considering contributing! It’s people like you who make this tool better for everyone traveling to our National Parks.

## How Can I Contribute?

### Reporting Bugs
* Check the **Issues** tab to see if the bug has already been reported.
* If not, open a new issue. Include your Node.js version and a clear description of what happened.

### Suggesting Enhancements
* Open an issue titled "Feature Request" and describe the functionality you'd like to see (e.g., "Add support for Grand Teton").

### Pull Requests
1. **Fork** the repository.
2. Create a **branch** for your fix (`git checkout -b fix/amazing-feature`).
3. **Commit** your changes (`git commit -m 'Add some amazing feature'`).
4. **Push** to the branch (`git push origin fix/amazing-feature`).
5. Open a **Pull Request**.

## Environment Setup
* Run `npm install`.
* Copy `config.example.json` to `config.json` and add your settings.
* Run `node index.js` to test.
